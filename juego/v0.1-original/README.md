# ¡Publicá la web! — MVP

Juego educativo breve para afianzar:
- página web
- sitio web
- hosting
- servidor
- dominio
- URL
- landing page

## Probar localmente
Abrí `index.html` en el navegador.

## Publicar en GitHub Pages
Subí `index.html`, `style.css` y `game.js` al repositorio y activá GitHub Pages desde Settings > Pages.

Esta primera versión no usa librerías ni recursos externos, para facilitar una futura conversión a PWA/offline.
