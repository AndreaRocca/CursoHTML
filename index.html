Módulo 1

La web por dentro

Usamos muchas palabras como si fueran sinónimos: página, sitio, landing, dominio, alojamiento. Pero no significan lo mismo.

25–35 min
📄

Página web

Un documento individual que se muestra en el navegador.

🗂️

Sitio web

Un conjunto organizado de páginas y recursos relacionados.

🎯

Landing page

Una página pensada para presentar una propuesta y orientar a una acción concreta.

🏷️

Dominio

El nombre o dirección que usamos para encontrar un sitio, por ejemplo ejemplo.com.ar.

🖥️

Alojamiento

El servicio donde se guardan los archivos para que estén disponibles en internet.

🌐

Navegador

El programa que solicita, interpreta y muestra el contenido web.
