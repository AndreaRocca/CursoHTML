Antes de jugar

¿Dónde vive una página web?

Paso 1 de 5

1. Una página comienza como un archivo

Podemos escribir instrucciones en un archivo de texto y guardarlo con la extensión .html. Esa extensión indica que contiene código HTML.

📄 index.html

2. El archivo puede estar en una carpeta

Antes de publicarlo, puede estar guardado en cualquier carpeta de la computadora junto con otras páginas e imágenes.

📁 mi-proyecto→📄 index.html🖼️ logo.png

Si movemos archivos, debemos revisar que los enlaces y las imágenes sigan apuntando al lugar correcto.

3. El navegador interpreta el HTML

Chrome, Firefox o Edge pueden abrir el archivo, leer sus etiquetas y convertirlas en títulos, párrafos, imágenes y botones.

file:///C:/mi-proyecto/index.html

Mi emprendimiento

Página abierta desde la computadora.

4. Una página no es lo mismo que un sitio

Cada archivo HTML puede representar una página. Varias páginas y recursos relacionados forman un sitio web.

InicioProductosContacto
3 páginas → 1 sitio web

5. Verla no significa publicarla

El navegador puede mostrar un archivo local, pero otras personas no pueden entrar desde sus dispositivos mientras permanezca solamente en tu computadora.

Pregunta puente: Martina abre index.html en su notebook y lo ve perfectamente. ¿Su página ya está publicada?

🗂️

Antes de jugar

De la carpeta a Internet

Paso 1 de 6

1. Recordemos el punto de partida

Tu archivo index.html funciona en el navegador, pero sigue siendo local. Para que otras personas lo vean hay que publicarlo.

💻 Archivo local→ publicar →🌍 Internet

2. Hosting y servidor trabajan juntos

El hosting o alojamiento es el servicio que guarda y mantiene disponibles los archivos. Esos archivos se encuentran en una computadora preparada para responder solicitudes: el servidor.

☁️ Servicio de hostingusa🖥️ Servidor

3. El dominio es un nombre fácil de recordar

En lugar de memorizar una dirección técnica, usamos un dominio como chimeleta.com.ar. En Argentina los dominios terminados en .ar se registran y administran mediante NIC Argentina.

🇦🇷 chimeleta.com.ar🌎 proyecto.com

.com es internacional y genérico; no pertenece exclusivamente a Estados Unidos. El dominio territorial estadounidense es .us.

4. La URL indica una ubicación completa

El dominio es una parte de la dirección. La URL es la dirección completa de una página, imagen u otro recurso e incluye información más precisa sobre dónde encontrarlo.

https://chimeleta.com.ar/productos.html

Dominio: chimeleta.com.ar

Ruta: /productos.html

URL completa: https://chimeleta.com.ar/productos.html

Un mismo dominio puede tener muchas URL diferentes: una para Inicio, otra para Productos y otra para Contacto.

5. Las terminaciones también comunican

Existen muchas terminaciones: .com suele asociarse con actividades comerciales, .edu con instituciones educativas, .org con organizaciones, .tv se usa con frecuencia en proyectos audiovisuales y .ar identifica a Argentina.

Las reglas para registrar cada terminación pueden ser diferentes. La terminación orienta, pero no explica por sí sola todo lo que hace un sitio.

6. Una landing page tiene una misión concreta

Una landing page es una página diseñada para recibir visitantes de una campaña y guiarlos hacia una acción principal: inscribirse, descargar, reservar o comprar.

📣 Anuncio→🎯 Landing page→✅ Inscripción

Pregunta puente: una campaña de una semana busca que las personas se inscriban a un taller. ¿Qué conviene crear?

Cuatro decisiones antes de diseñar

Paso 1 de 4

1. Propósito: ¿para qué existe el sitio?

El propósito es el resultado que la organización busca conseguir: informar, vender, recibir consultas, conseguir inscripciones, convocar o presentar un proyecto.

🏢 Organizaciónquiere🎯 Lograr algo

2. Destinatarios: ¿con quién queremos comunicarnos?

Un sitio no habla de la misma manera a niñas y niños, familias, clientes, estudiantes o especialistas. Reconocer a los destinatarios ayuda a decidir el tono, la información y las imágenes.

👥 Personas concretasnecesitan💬 Un mensaje adecuado

3. Propuesta de valor: ¿por qué elegir esta propuesta?

Explica de manera breve qué ofrece la organización, qué necesidad resuelve y qué la diferencia. No alcanza con decir “calidad” o “excelencia”: conviene ser específico.

Plantas fáciles + ayuda para aprender a cuidarlas

4. Llamada a la acción: ¿qué queremos que haga la persona?

Es una indicación visible y concreta: “Inscribirme”, “Consultar”, “Ver productos”, “Reservar turno” o “Descargar”. Debe estar relacionada con el propósito.

👤 Visitante→🔘 Reservar un turno
