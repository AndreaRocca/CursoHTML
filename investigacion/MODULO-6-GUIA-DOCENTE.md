# Módulo 6 · Una identidad con CSS

## Propósito

Iniciar CSS sin mezclar todavía hojas externas ni una lista extensa de propiedades. El grupo parte de una página HTML y aprende a modificar su presentación con reglas internas dentro de `<style>`: selector, propiedad y valor. La clase conserva el encargo de Martina y concluye con un PDF individual para Classroom.

## Secuencia sugerida para 90 minutos

- **0–10 min · Apertura docente.** Recuperar la comparación: HTML organiza el contenido como un esqueleto; CSS decide su presentación, como la vestimenta. Mostrar que el mismo HTML puede verse diferente.
- **10–25 min · Microlección y regla armable.** Recorrer las cuatro explicaciones y construir `h1 { color: purple; }`. Permitir reintentos y pedir que nombren cada parte.
- **25–40 min · Misiones de reparación.** Resolver selector, dos puntos, ubicación de `<style>` y contraste. Las pistas orientan; ver la solución queda registrado, pero no penaliza.
- **40–68 min · Producción.** Recuperar el código del módulo anterior si está disponible o usar la plantilla autónoma. Aplicar color, fondo, tipografía y alineación desde el bloque `<style>` del `head`. El editor ocupa todo el ancho y la vista aparece debajo.
- **68–78 min · Prueba con otra persona.** Preguntar qué llama primero la atención, qué cuesta leer y qué decisión visual cambiarían. Registrar una mejora concreta.
- **78–90 min · Metacognición y entrega.** Completar las cinco preguntas, preparar el informe, imprimirlo como PDF y adjuntarlo en Classroom. Descargar también el HTML como respaldo para otra computadora.

## Contenidos deliberadamente acotados

Se trabaja CSS interno mediante selectores de etiquetas. El estilo en línea se presenta como válido para un caso puntual, aunque menos práctico cuando se repite. Las clases, las hojas `.css` externas, el modelo de caja y los diseños complejos quedan para módulos posteriores. El punto y coma se enseña como separador necesario entre varias declaraciones, no como una condición mágica para que todo CSS funcione.

## Qué observar en el aula

- Si distinguen el selector de la propiedad y del valor.
- Si colocan `<style>` dentro de `head` o intentan escribir CSS suelto en `body`.
- Si comprenden que una regla en `<style>` evita repetir la misma decisión como atributo en varias etiquetas.
- Si el andamiaje cercano al editor reduce consultas puramente sintácticas.
- Si eligen colores legibles y pueden justificar sus decisiones más allá de «queda lindo».
- Cuánto tiempo demandan las reparaciones y la producción, y qué tramo conviene ajustar.

## Alcance de la corrección automática

Las verificaciones detectan estructura y algunas propiedades esperadas; no califican creatividad, autoría, accesibilidad completa ni calidad comunicativa. Los intentos y ayudas se incluyen para reconstruir el proceso, no para descontar puntaje. La docente conserva la evaluación final del código y del PDF recibido en Classroom.

## Continuidad entre computadoras

El guardado del navegador sirve solo mientras se usa la misma máquina y el mismo perfil. Para continuar otro día, cada estudiante debe descargar su archivo `modulo6.html` y entregar o guardar el PDF. El curso no afirma haber enviado archivos a Classroom ni sincroniza cuentas.
